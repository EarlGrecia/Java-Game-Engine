The Java Game Engine is an unfinished personal project utilizing the Java language, as well as the Lightweight Java Game Library (LWJGL)
and the Open GL external libraries. The project was developed using the Eclipse IDE, and was an exercise in practicing
beginner Computer Graphics concepts and exploring further Object-Oriented Programming topics prior to taking CMSC 132.

Because of further knowledge in other computer graphics libraries and the nature of OpenGL, as well as other commitments and shifting
interest with programming languages, development of the graphics engine has stalled. However, there are current plans to revisit
once the time is right. For now, the graphics engine includes features such as manual camera movement and motion blur.
